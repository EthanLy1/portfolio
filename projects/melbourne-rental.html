About the Project

Full-Stack Data Analytics & Visualisation Dashboard (Solo Developer). A comprehensive interactive platform for analyzing Melbourne's rental market data by suburb, property type, and time period. The project demonstrates end-to-end data engineering—from raw Excel data to production-ready insights—combining exploratory data analysis, REST API development, and modern reactive UI design to uncover housing market trends and affordability patterns.

My Role

Designed and implemented the complete pipeline: data cleaning and transformation with Pandas, PostgreSQL schema design with SQLAlchemy ORM, RESTful API endpoints with FastAPI/CORS, and an interactive React dashboard. Built dynamic filtering system, multi-chart visualisations (Recharts), interactive geospatial mapping (Leaflet), and summary statistics. Deployed backend on Render and frontend on Vercel with CI/CD integration.
