Melbourne Rental Intelligence

An interactive analytics platform exploring Melbourne's rental market across 119 suburbs — from raw government data to a live, filterable dashboard.

Python Pandas PostgreSQL SQLAlchemy FastAPI React Recharts Leaflet Vite Axios
Live Demo View on GitHub LinkedIn Post

The Goal

Replace tedious manual suburb comparisons with a single interactive dashboard. Uncover rent trends, affordability hotspots, and regional patterns — all from one place.

My Role

Solo full-stack developer. I handled the entire pipeline: cleaning raw Excel data with Pandas, designing a PostgreSQL schema, building a FastAPI backend, and creating an interactive React frontend — deployed end-to-end.

Development Journey

Data Engineering

Loaded raw Excel data from the Victorian Government. Cleaned and transformed it with Pandas — handled missing values with NaN conversion, filtered regions outside Melbourne, standardised column names, and performed exploratory analysis including regional comparisons and suburb rankings.

Data cleaning & exploration in Jupyter

Database

Set up PostgreSQL database on Neon with a clean rental dataset. Structured data with logical tables and used SQLAlchemy ORM for type-safe database operations.

pgAdmin SQL query

API Development

Built a FastAPI backend that serves rental market data via RESTful API, connecting to PostgreSQL with SQLAlchemy ORM and enabling cross-origin requests through CORS middleware.

FastAPI endpoint testing

Frontend Implementation

Built the React dashboard with reusable chart components (Recharts), interactive map (Leaflet), dynamic filters, and responsive layout — all connected to a FastAPI backend.

Interactive dashboard UI

Deployment

Deployed the FastAPI backend and React frontend on Render. Database hosted on Neon. Version controlled with GitHub for tracking changes throughout development.

Production deployment on Render
